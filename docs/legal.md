## Mods cerrados

- GTNH mantiene una hoja pública de permisos por mod, enlazada desde la página [Development](https://wiki.gtnewhorizons.com/wiki/Development) de la wiki ✅. Incluye la categoría "permisos especiales concedidos a GTNH".
- Es razonable suponer que esos permisos **no se transfieren** a un derivado ⚠️.
  - Ejemplo: Thaumcraft 4 solo permite redistribuirlo con permiso escrito ✅, según el texto de su página en CurseForge.
- **Conclusión:** un overlay que exige tener GTNH instalado y solo distribuye archivos propios evita el problema.

## Postura de GTNH

- No quieren modos de dificultad en el pack oficial ✅. En el [issue #3589](https://github.com/GTNewHorizons/GT-New-Horizons-Modpack/issues/3589) (2018): *"I dont think anyone would redo all of the 1000+ quests for a 'hard mode' or 'easy mode' config"*.
- No hay una política escrita sobre forks o derivados: no se encontró en la wiki ni en GitHub ✅ (se verificó la ausencia).
- Por cortesía, este proyecto lleva sus propios issues y no reporta nada a GTNH con el overlay instalado.

## Nombre

- No se encontró que "GTNH" sea una marca registrada ⚠️.
- Technic prohíbe usar el título de otro pack en el tuyo ✅.
- "GTNH Easy Mode" sirve como nombre de trabajo del repo. Para publicar, mejor un **nombre propio** con un aviso como: *"capa no oficial para GregTech: New Horizons; sin afiliación con el equipo de GTNH"*.
- No usar el logo de GTNH.

## Distribución

| Canal | Regla clave |
|---|---|
| GitHub Releases | Sin restricciones extra. Recomendado para el overlay ✅ |
| CurseForge | Solo admite mods de fuera de CurseForge con licencia abierta o con permiso explícito para packs ✅ |
| Modrinth | Solo permite descargas directas desde Modrinth, GitHub o GitLab ✅ |
| Technic | El creador del pack consigue los permisos y no puede usar el título de otro pack ✅ |

GTNH se distribuye desde gtnewhorizons.com, CurseForge y Technic. No tiene versión oficial en Modrinth ✅.
